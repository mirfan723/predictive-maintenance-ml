# Predictive Maintenance — Imbalanced Classification + Deployed Inference API

Predicts industrial machine failure from sensor readings (AI4I 2020 dataset), with a
focus on handling severe class imbalance (3.4% failure rate) properly rather than
optimizing for misleading accuracy. Includes model comparison (SVM, decision tree,
random forest, XGBoost), SHAP explainability, and a deployed FastAPI inference endpoint.

## Setup

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

## Run

```bash
uvicorn api.main:app --reload --port 8000
```

Interactive API docs (auto-generated by FastAPI): **http://localhost:8000/docs**

## Example request

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "machine_type": "M",
    "air_temperature_k": 300.5,
    "process_temperature_k": 310.2,
    "rotational_speed_rpm": 1500,
    "torque_nm": 40.0,
    "tool_wear_min": 100
  }'
```

Response:
```json
{
  "failure_predicted": false,
  "failure_probability": 0.03,
  "model_used": "XGBoost (weighted)"
}
```

## Explainability

SHAP values are used to explain both global feature importance (which sensor readings
drive failure predictions overall) and individual predictions (why a specific reading
was flagged as high-risk) — see `notebooks/analysis.ipynb`.

## Known limitations

- Trained on a synthetic (though realistic) dataset — real sensor data would likely
  have different noise characteristics and drift over time, requiring monitoring and
  periodic retraining in a real deployment.
- No authentication on the API — fine for a local/portfolio demo, not production-ready
  as-is.
